# Hot Potato - Video Game Compressor

A lightweight tool to compress game video files and save disk space.

## How to Setup
Because FFmpeg is too large to host here, follow these steps to set up your local engine:

1. **Download the Engine:** Go to the [Official FFmpeg Download Page](https://ffmpeg.org/download.html).
2. **Select your OS:** Click the Windows icon and choose the "gyan.dev" link.
3. **Get the Executable:** Download the `ffmpeg-release-essentials.zip` file.
4. **Install:** Extract the folder, go into the `bin` folder, and copy **`ffmpeg.exe`**.
5. **Paste:** Move `ffmpeg.exe` into the same folder where you have your `core.py` and `run_potato.bat` files.

## How to Run
1. Navigate to your game folder.
2. Ensure `core.py`, `run_potato.bat`, and `ffmpeg.exe` are all in the same folder.
3. Double-click `run_potato.bat`.
